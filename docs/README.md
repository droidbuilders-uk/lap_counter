# LapCounter Pro Documentation

Welcome to the LapCounter Pro documentation. This system uses ATtiny45 transponders and an ESP32 sensor bar to accurately track RC droids using infrared timing gates.

- [Quickstart Guide](quickstart.md) - Learn how to set up a race and use the Web UI.
- [Hardware Guide](hardware.md) - Part recommendations for transponders, sensor bars, and the LCD screen.
- [Wiring Diagrams](wiring.md) - Mermaid diagrams showing how to wire the microcontrollers and LEDs.
- [Installation Guide](installation.md) - Instructions for installing the `.deb` package on a Raspberry Pi.
